# Nuclei漏洞扫描使用指南

## 简介

Nuclei是一个基于模板的安全漏洞扫描工具，它允许使用简单的YAML格式定义扫描模板，能够快速、高效地发现各种安全漏洞。本平台已集成Nuclei工具，提供了友好的Web界面，使您可以轻松地进行漏洞扫描。

## 功能特点

- **多种模板类型**：支持技术识别、CVE漏洞、通用漏洞、敏感信息泄露、错误配置等多种模板类型
- **严重级别过滤**：可按信息、低、中、高、严重级别过滤扫描结果
- **可配置参数**：可设置线程数和超时时间，平衡扫描速度和系统负载
- **结果分析**：提供漏洞列表、严重级别分布、漏洞类型分布等多维度分析
- **历史记录**：保存扫描历史记录，方便追踪和比较
- **结果导出**：支持将扫描结果导出为JSON或CSV格式

## 使用方法

### 1. 访问漏洞扫描页面

在平台导航菜单中点击"漏洞扫描"，进入漏洞扫描页面。

### 2. 配置扫描参数

#### 基本参数
- **目标URL/域名**：输入要扫描的目标URL或域名，例如`example.com`或`https://example.com`
- **模板类型**：选择要使用的扫描模板类型
  - `technologies`：技术识别，用于识别目标使用的技术栈
  - `cve`：CVE漏洞，用于检测已知的CVE漏洞
  - `vulnerabilities`：通用漏洞，用于检测常见的安全漏洞
  - `exposures`：敏感信息泄露，用于检测敏感信息泄露问题
  - `misconfiguration`：错误配置，用于检测安全配置错误
  - `all`：使用所有模板进行全面扫描
- **严重级别**：选择要检测的漏洞严重级别
  - `info`：信息级别，包括所有级别
  - `low`：低级别，包括低级及以上
  - `medium`：中级别，包括中级及以上
  - `high`：高级别，包括高级及以上
  - `critical`：严重级别，仅包括严重级别
  - `all`：所有级别

#### 高级参数
- **线程数**：设置扫描线程数，建议值为10-50，根据目标系统性能和您的网络带宽调整
- **超时时间**：设置扫描超时时间（分钟），建议值为2-10，扫描大型目标时可适当增加

### 3. 开始扫描

配置完参数后，点击"开始扫描"按钮，系统将开始执行漏洞扫描。扫描过程中，您可以看到实时进度和已发现的漏洞数量。

### 4. 查看扫描结果

扫描完成后，系统将显示扫描结果，包括：

- **漏洞列表**：显示所有发现的漏洞，包括漏洞名称、严重级别、漏洞类型、影响URL等信息
- **严重级别分布**：以图表形式展示不同严重级别漏洞的数量分布
- **漏洞类型分布**：以图表形式展示不同类型漏洞的数量分布

点击漏洞列表中的某个漏洞，可查看该漏洞的详细信息，包括漏洞描述、参考链接、修复建议等。

### 5. 导出结果

点击"导出结果"按钮，可将扫描结果导出为JSON或CSV格式，方便进一步分析和报告生成。

### 6. 查看历史记录

在"扫描历史"标签页中，可查看所有历史扫描记录，包括扫描时间、目标、发现的漏洞数量等信息。点击某条记录，可查看该次扫描的详细结果。

## 最佳实践

1. **从小范围开始**：首次使用时，建议先选择特定模板类型（如`technologies`）和较高的严重级别（如`high`）进行小范围扫描，熟悉工具后再进行全面扫描
2. **合理设置线程数**：线程数越高，扫描速度越快，但也会对目标系统造成更大负载，请根据目标系统性能合理设置
3. **定期扫描**：建议定期对重要系统进行漏洞扫描，及时发现和修复安全问题
4. **结合其他工具**：将Nuclei扫描结果与其他安全工具（如端口扫描、指纹识别）的结果结合分析，获得更全面的安全评估

## 注意事项

1. **授权使用**：请确保您有权对目标系统进行安全扫描，未经授权的扫描可能违反法律法规
2. **避免过度扫描**：过于频繁或高强度的扫描可能导致目标系统性能下降，甚至触发安全防护机制
3. **结果验证**：Nuclei可能会产生误报，建议对重要漏洞进行人工验证
4. **安全存储**：扫描结果可能包含敏感信息，请妥善保管和使用

## 故障排除

1. **扫描无结果**：检查目标URL是否正确，尝试使用不同的模板类型，确认目标系统是否可访问
2. **扫描速度慢**：适当增加线程数，检查网络连接，考虑目标系统是否有限流措施
3. **结果解析错误**：检查Nuclei版本是否最新，尝试使用不同的输出格式
4. **系统报错**：查看系统日志，确认Nuclei工具是否正确安装和配置

## 更新Nuclei

为了获取最新的漏洞检测能力，建议定期更新Nuclei工具和模板：

```bash
# 更新Nuclei工具
cd info_vuln_platform/sectools/Nuclei
wget https://github.com/projectdiscovery/nuclei/releases/latest/download/nuclei_<版本号>_linux_amd64.zip
unzip nuclei_<版本号>_linux_amd64.zip
chmod +x nuclei

# 更新Nuclei模板
./nuclei -update-templates
```
