# 信息收集渗透测试平台

这是一个基于Python Django和Layui开发的自动化信息收集和渗透测试平台，提供了用户管理、指纹管理、子域名管理、POC管理、信息收集、漏洞扫描等功能。

## 功能特点

### 用户管理
- 用户列表：查看所有用户信息
- 用户操作：添加用户、编辑用户、删除用户、禁用用户
- 用户日志：查看用户扫描日志和操作记录

### 指纹管理
- 指纹分类：管理不同类型的指纹分类
- 指纹操作：添加、编辑、删除指纹（添加指纹时，下拉列表选择分类）
- 指纹搜索：根据名称和分类筛选指纹

### 子域名管理
- 子域名列表：查看所有子域名信息
- 子域名操作：添加、编辑、删除子域名
- 子域名搜索：根据主域名和子域名筛选

### POC管理
- POC分类管理：基于Nuclei模板，分类管理POC（CMS、设备、框架等）
- POC操作：添加、编辑、删除POC
- POC搜索：根据名称和分类筛选POC

### 信息收集
- 基础信息：CDN检测、WHOIS查询、备案信息查询
- 高级功能：调用IEyes识别收集信息

### 工具调用
- 端口扫描：调用naabu扫描端口、获取扫描结果
- 目录扫描：调用dirmap扫描目录、获取扫描结果
- 指纹识别：调用TideFinger_Go识别指纹、获取扫描结果
- 子域名爆破：调用dnsub爆破子域名、获取扫描结果
- 漏洞扫描：调用Nuclei扫描漏洞、获取扫描结果

### 报告管理
- 报告生成：在每个扫描结果后点击按钮生成HTML扫描报告
- 扫描日志：记录每次扫描的日志和扫描结果

## 技术栈

- 后端：Python Django
- 前端：Layui
- 数据库：SQLite（可扩展至MySQL、PostgreSQL等）
- 工具集成：naabu、dirmap、TideFinger_Go、dnsub、Nuclei等

## 安装与使用

### 环境要求

- Python 3.8+
- Django 5.1+
- 相关工具依赖（详见requirements.txt）

### 安装步骤

1. 克隆代码库
```bash
git clone https://github.com/yourusername/info-test-platform.git
cd info-test-platform
```

2. 安装依赖
```bash
pip install -r requirements.txt
```

3. 初始化数据库
```bash
cd info_vuln_platform
python manage.py migrate
```

4. 创建管理员用户
```bash
python manage.py create_admin --username admin --password admin123 --email admin@example.com
```

5. 启动开发服务器
```bash
python manage.py runserver
```

6. 访问系统
在浏览器中访问 http://127.0.0.1:8000/

### 默认管理员账号

- 用户名：admin
- 密码：admin123

## 目录结构

- `info_vuln_platform/`: 项目主目录
  - `manager/`: 管理员应用
  - `templates/`: HTML模板
  - `static/`: 静态文件
  - `layui-v2.9.23/`: Layui前端框架

## 模块说明

### 用户管理模块
用户管理模块提供了用户的增删改查功能，管理员可以添加新用户、编辑用户信息、删除用户、禁用用户，以及查看用户的操作日志。

### 指纹管理模块
指纹管理模块用于管理Web应用、服务、系统等的识别指纹，包括指纹分类管理和指纹管理两部分。用户可以添加、编辑、删除指纹分类和指纹，并通过搜索功能快速找到所需的指纹。

### 子域名管理模块
子域名管理模块用于管理目标域名的子域名信息，包括子域名的添加、编辑、删除功能。用户可以记录子域名的IP地址、状态码、网站标题、服务器信息等。

### POC管理模块
POC管理模块基于Nuclei模板，用于管理不同类型的漏洞验证脚本。用户可以添加、编辑、删除POC，并按照分类（如CMS、设备、框架等）进行管理。

### 信息收集模块
信息收集模块提供了多种信息收集功能，包括CDN检测、WHOIS查询、备案信息查询等基础功能，以及调用IEyes进行高级信息收集。

### 工具调用模块
工具调用模块集成了多种安全工具，包括端口扫描工具naabu、目录扫描工具spray、指纹识别工具TideFinger_Go、子域名爆破工具dnsub、漏洞扫描工具Nuclei等。用户可以通过Web界面调用这些工具进行扫描，并查看扫描结果。

### 报告管理模块
报告管理模块用于生成和管理扫描报告。用户可以在每次扫描完成后生成HTML格式的扫描报告，并查看历史扫描日志和结果。
